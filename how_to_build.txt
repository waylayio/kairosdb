Building requires JDK 25 or later and Maven 3.6+.

To build and run tests:
  mvn clean test

To build a JAR package:
  mvn clean package

To build without running tests:
  mvn clean package -DskipTests

Docker build:
  docker build -t kairosdb:2.0.0 .
  docker run -it --rm -p 0.0.0.0:8080:8080 -p 0.0.0.0:4242:4242 kairosdb:2.0.0
